- vercel.json: configuração simples para publicação

COMO PUBLICAR:
1. Extraia o ZIP.
2. Crie um repositório no GitHub e envie TODOS os arquivos e a pasta assets.
3. Na Vercel, escolha Add New > Project.
4. Importe o repositório do GitHub.
5. Framework Preset: Other.
6. Build Command: deixe em branco.
7. Output Directory: . (ponto) ou deixe o padrão.
8. Clique em Deploy.
